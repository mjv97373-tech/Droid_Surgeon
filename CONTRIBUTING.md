# Contributing to Droid Surgeon

First off, thanks for taking the time to contribute! 

## How to report a bug
* Check the issue tracker to see if the bug has already been reported.
* If not, open a new issue. Please include your OS, Python version, and the exact error traceback.

## How to suggest a feature
* Open an issue with the "enhancement" tag and clearly describe why this feature would be useful.

## Pull Request Process
1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the code follows the existing style (PEP 8 for Python).
4. Update the README.md with details of changes to the interface, if applicable.
5. Issue that Pull Request!
